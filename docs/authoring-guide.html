Home Page Authoring Guide

Holland America Line — Edge Delivery Services (da.live)

Overview

This guide explains how to author the home page using the available blocks in da.live. The page is composed of sections, each containing one or more blocks. Sections are separated by horizontal rules (---).

Important: The Header and Footer are authored as separate documents (nav and footer) and are automatically included on every page. You do not add them to individual pages.

1. Header (Global Navigation)

Document: nav (root level)

Create a document named nav at the root of your content folder. Structure it with 3 sections separated by horizontal rules:

Section 1 — Brand / Logo

A single paragraph with a link to the homepage:

Holland America Line   (linked to /)

Section 2 — Navigation Links

A bulleted list. Sub-items become dropdowns:

• Find a Cruise (link to /find-a-cruise)
  • Alaska (link to /cruise-destinations/alaska-cruises)
  • Caribbean (link to /cruise-destinations/caribbean-cruises)
  • Mediterranean (link to /cruise-destinations/mediterranean-cruises)
• Destinations (link to /cruise-destinations)
  • Alaska
  • Caribbean
• Onboard (link to /onboard-experiences)
  • Dining
  • Entertainment
• Ships (link to /cruise-ships)
• Plan (link to /plan-a-cruise)

Section 3 — CTA Button

A bold link becomes the action button (top right):

Book Now   (linked to /find-a-cruise)
Tip: The nav document is shared across all pages. Edit once → updates everywhere.

What Gets Rendered

  • Title + description + pill-shaped CTA button (white border)
  • Cards auto-populated from Fusion API with:
    • Itinerary route map image
    • Cruise name (e.g., "7-Night Alaska Inside Passage")
    • Ship name + departure date
    • Price (from $X* per person)

Note: The card content is dynamic — you only author the header section. The cards are populated automatically from live search data.

Authoring Tips

  • Section breaks: Add a horizontal rule (---) between each section in your document
  • Block names: The first row of a table (merged across columns) must match the block name exactly: Hero, Card Carousel, Cruise Filter, Cruise Results
  • Buttons: Bold link = primary button. Bold + italic link = accent (orange) button. Plain link = text link.
  • Images: Paste directly into the table cell. Use high-resolution images for best results.
  • Preview: Use the AEM Sidekick "Preview" button to see your changes on the preview environment.
  • Publish: Once satisfied, click "Publish" in the Sidekick to make changes live.
